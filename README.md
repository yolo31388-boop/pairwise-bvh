# 游戏内BVH层次包围盒系统

## 项目描述

游戏内BVH层次包围盒系统的bug修复项目。核心模块 `spatial/bvh.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- BVH构建完全没做光线遍历是O(n)
- 遍历完全没做不能快速遍历树
- 更新完全没做不能动态更新BVH
- 光线相交完全没做不能计算光线与三角形相交
- BVH质量完全没做不能评估BVH质量

## 运行测试

```bash
python -m pytest tests/test_bvh.py -q
```

修复目标：所有 14 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
